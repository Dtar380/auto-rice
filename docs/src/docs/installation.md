# Installation

## Prequisites

First you need to have installed Arch linux on your system, for doing so you can check their [wiki](https://wiki.archlinux.org/title/installation_guide).

Before proceding with the installation you need to make sure you have already installed:

- A stable network connection (for wireless check [this](https://wiki.archlinux.org/title/NetworkManager))
- Installed git (use `sudo pacman -S git` once you've installed Arch propperly)

## Installing

Follow the next steps:

1. Clone the repo by running `git clone https://github.com/Dtar380/auto-rice.git`
2. Move inside the directory of the repo by running `cd auto-rice/src`
3. Make the script executable by running `sudo chmod +x ./install`
4. Run the script simply by typing `./install`
